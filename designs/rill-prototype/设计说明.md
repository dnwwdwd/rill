## 设计判断

Rill 不是「又一个阅读器」，而是一条把标准 Feed、X、公众号收进同一处的河道。原型因此采用 **「纸页与水位线」** 的方向：

- 纸页：正文区域是可读的暖白纸面，标题用宋体，UI 用黑体，信息密度靠细线和留白组织，不靠卡片堆叠。
- 水位线：深青色是所有交互与品牌色的唯一来源；侧边栏的源列表带一条纵向刻度线，用来表达「同一条管线」。
- 信号色：朱砂只用于未读、需授权、危险操作等需要被看见的状态，不参与装饰。
- 仪器感：时间、未读数、抓取耗时使用等宽数字；状态用文字 + 色点，不靠图标猜。

## 预览

多文件原型需要通过 HTTP 打开（直接双击 `index.html` 不会加载 `.jsx`）：

```bash
python3 -m http.server 4311 --directory designs
```

打开 <http://localhost:4311/rill-prototype/index.html>。原型栏可切换 6 个页面与「桌面 / 手机」视图；登录页输入任意非空密码即可进入。

## 已实现的原型交互

- 原型栏切换 6 个页面；「桌面 / 手机」切换是容器级响应式预览，不是两张静态图。
- 登录表单校验；空密码给出可读错误。
- 收件箱 / 未读 / 收藏 / 已读筛选；按源、按文件夹筛选；文件夹折叠。
- 条目选中后延时标记已读；`j` / `k` 移动，`m` 已读，`s` 收藏，`o` 打开详情。
- 详情页原文 / 译文 / 双语切换，不重复模拟模型调用；AI 摘要折叠、重新生成；AI 关闭与未确认外发时阻止调用。
- 添加源弹层：网址发现 Feed、X handle、公众号三种路径；发现结果可选择并添加。
- 源列表启停、进入诊断页；诊断页手动刷新、切换备用源、编辑源（名称 / 文件夹 / 间隔 / 备用源）、查看抓取历史、重置令牌、删除源。
- 设置中的字号、行宽、行高、主题即时生效；AI 开关、测试连接、公众号扫码状态、公众号采集总开关、备份与 token 重置均有反馈。
- 手机端：列表 / 阅读两级切换、底部导航、抽屉式源树、全宽表单、设置分类双列导航。

## 原型边界

- 所有数据为演示数据；不连接真实后端，不发起除本地静态资源外的网络请求。
- 二维码为占位图形；点击可模拟扫码成功，仅用于展示登录态变化。
- 图片使用带标注的占位块，避免用假图冒充真实媒体代理结果。
- 未写入任何真实 API Key、Cookie、OAuth token 或 Feed token。
