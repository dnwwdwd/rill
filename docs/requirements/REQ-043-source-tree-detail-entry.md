# REQ-043 订阅源 filetree 增加查看详情入口

- 状态：已实现（本地验证；真实浏览器待验收）
- 日期：2026-11-22
- 关联：PRD F-01/F-07、REQ-020

## 目标

设置 → 订阅源的 filetree 中，每个源行新增一个可见的「查看详情」入口，跳转到源详情页（抓取状态、日志、源信息），不再只依赖点击整行这一隐含交互。

## 范围

- 在源行的操作区新增 `activity` 图标按钮，`aria-label` 为「查看 {源名} 详情」。
- 点击后关闭设置并导航到 `/sources/{id}`；与点击源行原有行为一致。
- 按钮放在启停开关之后、编辑按钮之前；按钮自身阻止事件冒泡，不会触发行点击或勾选。
- 多选批量模式下不显示行操作，因此也不显示详情入口。
- 桌面设置弹窗与移动端设置页共用 `SourcesSettings`，两端同时生效。
- 不新增 API、schema 或后端字段。

## 验收

- filetree 每个源行都能看到「查看 {源名} 详情」按钮。
- 点击按钮直接打开对应源详情页；点击行其他区域行为不变。
- 多选模式下不出现该按钮，避免与勾选冲突。
- 现有编辑、刷新、启停、删除操作不受影响。

## 验证

- `npm run typecheck`、`npm test -- --run`、`npm run build`。
- 待验收：桌面/移动端真实浏览器入口位置与跳转。
