# REQ-039：侧栏订阅源树右键菜单与拖拽移动

- 状态：已完成（本地验证；真实浏览器/触屏待验收）
- 日期：2026-11-12
- 关联：PRD F-17/F-26/F-30/F-52/F-53/F-54、DESIGN §页面结构、PDD §4.2/§5.2/§6.5、REQ-003/REQ-020/REQ-038、DEC-015
- 数据边界：树操作复用 `folders.sort/parent_id` 与 `sources.folder_id`；阅读增强新增迁移 11（`items.later_at`、`item_notes`）；全文抓取复用 `sources.config_json`；保存视图存 `settings.reader.views`，不新增表

## 目标

1. 桌面侧栏订阅源树支持右键菜单，源与分组都能直接编辑、删除，不要求先进入设置页。
2. 支持拖拽源到分组/未分组/根区域，拖拽分组实现嵌套、同级排序与移回根目录。
3. 移动端/平板没有右键时，用长按打开同一菜单；菜单内提供「移动到分组」，保证触屏也能完成归类。
4. 所有破坏性操作二次确认；不改变现有权限、抓取、鉴权与数据语义。

## 交互规则

### 右键 / 长按菜单

- 源：打开、编辑订阅源、立即刷新、暂停/启用、移动到分组…、删除订阅源。
- 分组：添加订阅源、编辑分组、删除分组。
- 「移动到分组…」展开为分组列表（含「未分组」与当前勾选状态），避免触屏无法拖拽时无路可走。
- 菜单通过 Portal 挂到 `body`，按视口边界收拢；点击外部、Esc、窗口缩放/滚动时关闭。
- 键盘可用 `Shift+F10` / 菜单键打开；方向键移动焦点，Enter 执行。
- 长按约 500ms 打开菜单；移动超过 8px 取消，避免滚动时误触。
- 删除源：确认后连同文章删除；若当前正在看该源，回到「全部」。
- 删除分组：确认后分组内源回到「未分组」，子分组上移；若当前正在看该分组，回到「全部」。

### 拖拽

- 源拖到分组行：移入该分组；拖到「未分组」行或树底部根区域：移出分组。
- 源拖到另一个源：移入目标源所在分组（不改变文章排序）。
- 分组拖到分组中部：成为其子分组；拖到分组上/下缘：成为同级并插入到目标前/后。
- 分组拖到树底部根区域：移到根目录末尾。
- 分组不能拖到自身或自己的后代下；非法目标不显示落点反馈。
- 拖拽悬停到收起的分组时展开；移动成功后保持展开。
- 折叠父分组时隐藏其后代分组与源，避免 DnD 嵌套后出现无法解释的层级。
- 每个分组同级顺序写入现有 `folders.sort`；前端重排同级后逐项 PATCH，失败时重新加载真实顺序并提示。
- 触屏拖拽不作为硬要求；长按菜单提供同等归类能力。HTML5 拖拽只保证桌面鼠标/触控板。

## 实现

- 前端新增通用 `ContextMenu`、`ConfirmDialog`。
- `Sidebar` 增加菜单状态、长按识别、HTML5 拖拽状态与落点计算。
- `sourcesStore` 新增 `moveSource` / `moveFolder`：
  - `moveSource` → `PATCH /api/v1/sources/{id}` `{folder_id}`。
  - `moveFolder` → `PATCH /api/v1/folders/{id}` `{parent_id, sort}`（后端已支持）。
- `api.updateFolder` 增加可选 `sort` 参数；mock 同步持久化 `sort`。
- 不新增后端端点；不改变 `DELETE /folders` 的回落语义。

## 验收

- 右键源/分组均出现菜单；编辑源打开现有编辑弹窗，编辑分组打开现有分组弹窗。
- 删除源/分组均二次确认；取消不产生请求；确认后源树与设置页数量一致。
- 源可拖入分组、拖出到未分组/根区域；目标分组出现明确高亮/插入线。
- 分组可拖成子分组、同级前后排序、拖回根目录；自身/后代目标被拒绝。
- 折叠父分组后，其子分组与源都隐藏；展开恢复。
- 长按源/分组可打开菜单；菜单内「移动到分组」可完成归类。
- 刷新页面后分组层级与同级顺序保持。
- 现有 `SourcesSettings` 中的编辑/删除/批量操作不受影响。

## 2026-11-12 扩展实现

用户确认「除第 7 项搜索语法、第 9 项过滤自动归组、第 11 项源排序/删除撤销、第 13 项 Newsletter 外，其余一次实现」。本轮实际落地：

### 订阅源树与批量管理

- 源/分组 Ctrl/Cmd 多选、Shift 范围选择；批量移动、启用、暂停、刷新、删除；混选时源删除、分组只解除归属。
- 侧栏搜索源名称/Feed 地址；搜索结果自动展开祖先分组。
- 分组行聚合子树未读数、源数量与抓取失败标记；右键「全部标为已读」按子树生效（后端递归 CTE）。
- 折叠状态写入 localStorage（`rill.rail.collapsed.v1`），刷新后保持。
- 抓取失败源聚合为「N 个源需关注」入口，弹窗内可跳转单源或全部重试。
- 保存视图：保存当前筛选、搜索词与已读状态到 `settings.reader.views`（最多 30 个），跨设备同步；侧栏一键应用/删除。
- 分组右键新增「导出此分组 OPML」「导入 OPML 到此分组」；导出包含该分组及子树，导入落在目标分组下。

### 阅读列表

- 多选模式：Ctrl/Cmd 点选、Shift 范围选择；批量已读/未读、收藏/取消收藏、稍后读/移出、隐藏。
- 跨源重复合并：按规范化 URL（去除 utm 等追踪参数）或 ≥12 字规范化标题 + 7 天窗口，在已加载列表内折叠；行内显示「+N 源」，列表头可关闭并记忆到 localStorage。
- 命令面板：`⌘K` / `Ctrl+K` 搜索并跳转源、分组、设置，或直接以当前输入搜索文章。
- 侧栏新增「稍后读」入口与计数。

### 全文抓取（F-17）

- 每源「抓取全文」开关写入 `sources.config_json.full_text`，不新增列，作为新条目自动抓取模式。
- 正文/专注阅读右上角新增「抓取全文」按钮：对当前文章即时抓取（`POST /items/{id}/fulltext`），不需要去源设置；已有文章也能按需补全文。
- Feed 只给摘要时抓取原文页；优先 `article/main/[role=main]` 与常见正文容器，回退整页正文。
- 每次抓取最多处理 12 条新文章，并发 4、单条 7 秒超时；失败保留 Feed 摘要，不影响入库。
- 图片仍经媒体代理重写，全文抓取得到的图片必须合并进 `item.MediaURLs` 并登记 `media_cache`；只改写 HTML 不登记会让 `/media` 返回 404。`data:` 内联图片（如 Mermaid SVG）当前不属于可代理媒体，会被 sanitize 移除。正文为空/过短或提取结果不优于原摘要时跳过。

### 稍后读、笔记、高亮与朗读（F-53）

- 迁移 11（SchemaVersion 11）：
  - `items.later_at TEXT` + 部分索引。
  - `item_notes(id, item_id, quote, note, color, created_at, updated_at)`，颜色枚举 yellow/green/blue/pink，随条目级联删除。
- 接口：`PATCH /items/{id}/state` 与 `PATCH /items/state` 增加 `later`/`hidden`；`GET/POST /items/{id}/notes`、`PATCH/DELETE /items/{id}/notes/{note_id}`。
- 详情与专注阅读：工具栏加入稍后读、朗读、笔记；正文选中文字后点击「添加」自动带入摘录，保存后在正文用 `<mark>` 显示高亮，笔记列表可编辑/删除。
- 朗读使用浏览器 `SpeechSynthesis`，中文文本使用 `zh-CN`，切换文章/卸载时自动停止。
- 删除条目时笔记级联删除；备份恢复包含 `item_notes`。

### MCP 组织工具（F-50 扩展）

- 新增 `move_source`、`move_sources`、`reorder_folders`；仍不提供删除工具，不暴露密钥/设置/备份恢复。

### 本轮明确未实现

- 第 7 项搜索语法（`source:` / `folder:` / `is:` / `after:`）。
- 第 9 项过滤规则自动移动到分组/收藏。
- 第 11 项源手动排序与删除撤销/回收站。
- 第 13 项 Newsletter 收信。

## 仍未实现（本轮明确跳过）

| 功能 | 状态 / 原因 |
|---|---|
| 搜索语法（`source:` / `folder:` / `is:` / `after:`） | 用户本轮指定跳过；后续需扩展 `/items` 查询解析 |
| 过滤规则自动移动到分组/收藏 | 需要扩展过滤规则 action 枚举与迁移，用户本轮未批准 |
| 源手动排序、删除撤销/回收站 | 需要 `sources.sort` 或软删除，用户本轮未批准 |
| Newsletter 邮箱订阅 | 用户选择暂缓，需外部收信服务与凭据 |
| 分组默认刷新/保留策略、源标签/虚拟分组、Feed 自动修复 | 仍为候选，涉及 schema 或站点抓取策略 |
| 浏览器扩展、服务端 TTS、跨设备阅读统计 | 仍为远期候选 |

### 建议顺序

1. 先验收本轮：侧栏批量/视图、列表多选/重复合并、命令面板、分组 OPML、全文抓取、稍后读/笔记/朗读、MCP 组织工具。
2. 再评估用户明确跳过的四项，尤其是源手动排序/删除撤销需要迁移决策。
3. 最后考虑分组策略、标签、Newsletter 与浏览器扩展。

### 明确不做

- 不在侧栏右键菜单里放「重置 Feed Token」「备份恢复」「AI 密钥」等高风险操作。
- 不提供删除分组的级联删源；删除分组永远只解除归属。
- 不把触屏拖拽做成唯一路径；长按菜单必须能完成同样的事。
- 不为一次 UI 交互新增后端表；能用现有字段完成的，不升级 schema。
