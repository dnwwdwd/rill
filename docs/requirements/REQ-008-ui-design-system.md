# REQ-008 视觉系统刷新与黑白微信绿主题

- 状态：已完成（本地验证）
- 优先级：P1
- 关联功能：F-01、F-02、F-07、F-14、F-26、F-33、F-36、F-38、F-40、F-45
- 事实来源：[PRD.md](../../PRD.md)、[PDD.md](../../PDD.md) §6.5、[AGENTS.md](../../AGENTS.md)、[designs/rill-prototype/](../../designs/rill-prototype/)

## 目标

在不改变业务行为、API、数据结构和安全边界的前提下，统一现有前端的视觉语言：

- 主题色从深青切换为黑白 + 微信绿，保留「纸页」阅读感；按钮和统计卡不使用投影；选中态不再使用左侧色条。
- 页面头部、工具栏、卡片、列表行、空状态和弹层使用同一套间距、圆角、边框与阴影 token。
- 抽取可复用的搜索框、提示条、卡片/指标等基础组件，减少页面内重复样式。
- 增加图标在导航、页面标题、筛选、设置分类、状态与源类型中的表达力。
- 删除不承担信息职责的 secondary description，保留安全、失败、权限和不可逆操作说明。

## 范围

### 必须

- `web/src/styles/index.css` 统一 light/dark token，交互绿 + 微信绿双层；正文、状态色与危险色仍可区分。
- 阅读中栏不重复侧栏已有的筛选和统计，只保留标题、数量、搜索、全部已读和排序。
- `PageHeader` 支持图标；`SearchField`、`Notice`、`Card`、`Metric` 等基础组件落地并至少被两个页面复用。
- 侧边栏、阅读三栏、源管理、源诊断、设置、登录页完成视觉回归。
- 设置导航与页面头部去掉装饰性说明；按钮、输入、开关、标签、弹层、空状态统一新 token。
- 1440 / 1024 / 900 / 768 / 390 / 320 视口无横向溢出；浅色/深色均可读。
- 同步设计规范与项目进度证据。

### 不做

- 不新增路由、API、数据库字段或外部依赖。
- 不改变筛选、阅读、抓取、鉴权、Feed 输出行为。
- 不引入 Tailwind、CSS-in-JS 或图标库；继续使用手写 SVG `Icon`。
- 不修改原型的历史截图；原型只作为 v0.1 参考，现行 token 以 `docs/DESIGN.md` 为准。

## 风险与边界

- 仅视觉和组件层调整；如发现功能缺口，另建 REQ，不在本任务内顺手修业务逻辑。
- 保留 `remember_position` 等既有功能缺口的事实状态，不因 UI 刷新宣称为已完成；该缺口已在 v0.14 实现阅读位置恢复。
- 删除说明文字时不得删除安全外发确认、登录态失效、破坏性恢复、Token 泄露风险等必要提示。
