# REQ-017 详情页操作收敛与翻译上移

- 状态：已完成（本地验证）
- 优先级：P2
- 关联：[DESIGN.md](../DESIGN.md)、[PRD.md](../../PRD.md) F-07/F-46、[PDD.md](../../PDD.md) §6.5、[REQ-014](REQ-014-reader-list-controls.md)
- 影响代码：`web/src/components/reader/ReaderPane.tsx`、`web/src/components/reader/FocusReader.tsx`、`web/src/pages/ReaderPage.tsx`、`web/src/styles/index.css`

## 用户要求

1. 详情页右上角已有收藏、专注阅读等按钮，底部不应再重复。
2. 翻译入口移到右上角。
3. 看不懂右上角最右侧的三点图标，需要说明或改进。
4. 已读/未读筛选图标换回最初版本。

## 范围与规则

| 项 | 规则 |
| --- | --- |
| 底部操作 | 删除普通详情页与专注阅读页底部的收藏 / 专注 / 在源站打开 / 输出订阅按钮；操作只保留在顶部工具栏和专注阅读右栏。 |
| 翻译入口 | 普通详情页桌面工具栏新增翻译图标；点击打开紧凑浮层，内含「译文 / 原文 / 双语」和「生成译文」。正文不再重复渲染翻译面板。移动端与专注阅读右栏保留紧凑翻译面板。 |
| 翻译状态 | 浮层点击外部或 Esc 关闭；切换条目时自动关闭；翻译生成中沿用「正在翻译」状态。 |
| 三点图标 | 原 `more` 图标实际是「查看源诊断」，语义不清。移除详情页、专注页和移动端顶栏的该图标；把文章顶部的来源名称/图标改为可点击入口，点击进入 `/sources/{id}`，并保留 `title="查看源诊断"`。专注阅读右栏仍保留「查看诊断」文字按钮。 |
| 已读筛选图标 | 回退到最初的 `filter` / `unread` / `read`：漏斗 / 圆点 / 对勾；移除中途尝试的信封徽标图标。 |
| 不变 | 收藏、已读、外链、复制订阅地址、键盘快捷键和移动端底部导航不变。 |
