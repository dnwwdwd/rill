# REQ-001 X RSS 真实可用

- 状态：进行中
- 优先级：P0
- 关联功能：F-11（X 源）、F-27（首次回溯）、F-29（静默失败）、F-42（出站代理）、F-22（FxEmbed 自建降级）
- 事实来源：[PRD.md](../../PRD.md)、[PDD.md](../../PDD.md) §7.2、[RSS-SOURCES.md](../RSS-SOURCES.md) §3
- 功能进度：[PROG-REQ-001-x-rss](../progress/PROG-REQ-001-x-rss.md)

## 目标

用户输入一个 X handle，就能把该账号的公开帖子作为普通 Feed 收进 Rill：抓取、去重、清洗、阅读、输出，全程不使用 X Cookie、OAuth token 或官方 API Key。

## 当前实现

- 前端 X 标签页校验 handle，生成 `https://fxtwitter.com/{handle}/feed.xml?count=20`；可选回复、媒体和安全过滤参数。
- 后端 `kind=x` 只负责生成/保存 FxTwitter Feed URL，抓取完全走标准 RSS。
- 已有源诊断、失败退避、手动备用源和标准 Feed 输出。
- 本地 `httptest` 覆盖标准 RSS 解析与失败隔离。
- 2026-10-31 本机真实二进制联调时，X 源首次调度抓取失败，未取得真实帖子；**没有完成外部验收**。

## 范围

### 必须

- 无凭据添加 X 源。
- 真实 FxTwitter Feed 至少取得 1 条帖子，正文、作者、时间、图片/视频链接可用。
- 再次抓取不产生重复条目；条件请求行为符合标准 RSS。
- 抓取失败在源诊断和源列表可见，不阻塞其他源。
- 首条回溯上限与 `?count=20` 一致。

### 不做

- 不登录 X，不保存 X Cookie。
- 不实现 X 官方 API 适配器。
- 不在本期引入转推/回复的本地二次过滤；现有参数由 Feed URL 决定。
- 不把 FxEmbed 自动降级当作当前已完成能力。

## 未决问题

1. 微服出口能否直连 `fxtwitter.com` 与媒体域名？本机失败是网络、实例限流还是其他原因？
2. 失败后的正式降级选 FxEmbed 自建（F-22）还是 HTTP 出站代理（F-42）？需要用户确认。
3. 是否允许在源编辑页修改 X 的 `with_replies` / `media.xml` / `safe` 选项？当前只在添加时编码进 URL。
4. FxTwitter Feed 的 304/ETag 和静默停更行为需要实测。
