# REQ-037 关键字/正则过滤规则

- 状态：进行中（后端完成本地验证，前端进行中；见 DEC-027）
- 日期：2026-11-10
- 关联：PRD F-51、PDD §4/§9、DEC-027

## 目标

用户可配置关键字或正则规则，新条目入库时自动处理：标记已读或隐藏，实现信息降噪。过滤规则可与 REQ-036 报告组合使用（被隐藏的条目不进入报告）。

## 范围

1. 规则字段：名称、匹配模式（关键字或正则）、匹配字段（标题 / 正文 / 两者）、动作（`mark_read` 标记已读 / `hide` 隐藏）、作用范围（选定源 / 分组，空 = 全部源）、启用开关。
2. 应用时机：抓取入库（upsert）后按源评估启用规则；只作用于新入库条目。
3. 存量应用：规则可手动「应用到现有条目」，作用于范围内全部条目；已读/收藏条目不被取消已读或收藏。
4. 隐藏语义：`items.hidden=1` 的条目默认列表与报告不显示；设置内「已过滤」视图可查看并手动恢复。
5. 命中计数：记录 `hit_count` 便于评估规则效果。

## API

- `GET/POST /api/v1/filters/rules`、`PUT/DELETE /api/v1/filters/rules/{id}`
- `POST /api/v1/filters/rules/{id}/apply`（应用到存量）
- `GET /api/v1/items?hidden=1` 复用现有列表端点（新查询参数）。

## UI

设置「自动化」分类下的「过滤规则」区：规则列表与编辑、立即应用按钮、命中次数展示。

## 验收

- 新抓取的条目命中关键字后立即标记已读 / 隐藏，未命中不受影响。
- 正则非法时保存报错，不影响其他规则。
- 应用到存量后范围内条目按规则处理；隐藏条目从默认列表消失、可在「已过滤」视图恢复。
- 报告生成跳过 `hidden=1` 条目。

## 已知限制

- 不做相似文章聚合 / 去重聚合（用户明确不纳入）。
- 过滤只按标题/正文文本匹配，不做语义判断。
- 隐藏不删除数据，条目仍受保留策略约束。
