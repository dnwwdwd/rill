## 设计语言

**黑白纸页，强调色作印。** 界面以近黑文字、白色面板、浅灰工作区组织信息。默认强调色是品牌蓝（2026-11-02，跟随猫猫 icon 配色）：`#5B6CF0` 亮蓝用于品牌、开关、未读和进度，`#4C5EE8` 用于文字与链接。用户可在阅读设置中切换品牌蓝 / 微信绿 / 青碧 / 靛蓝 / 紫 / 娇粉 / 橙 / 琥珀 / 玫瑰；切换只改强调色层，不改纸张、正文和语义状态色。参考方向是克制的工具型应用：纸张微纹理、细线、留白和极轻的卡片层次，不靠大面积渐变、彩色卡片或按钮阴影制造重点。

四条规则：

1. **平面优先。** 页面、面板、卡片之间用纸色差和 1px 细线区分；按钮、工具栏、筛选、选中态不使用投影；卡片允许极轻阴影，弹层和 Toast 允许更明显的轻量阴影。
2. **强调色是动作色。** 默认品牌蓝；深色承担文字与主操作，亮色承担品牌、开关、未读和进度。语义状态色不随主题色改变，危险操作才用红色。
3. **图标承担导航，不替代文字。** 所有图标配 `aria-label` 或可见文字；同一区域图标尺寸一致，不使用 emoji。
4. **先给布局，再给解释。** 标签、分组、留白能说明的事情，不再补一段 secondary description。安全、失败、权限、不可逆操作说明除外。

### 主题色预设

- 存储：`settings.reader.accent`，取值 `blue | green | teal | indigo | purple | pink | orange | amber | rose`，默认 `blue`（品牌蓝，2026-11-02 起跟随猫猫 icon 配色；存量 `green` 用户保持所选值不变）。这是 settings JSON 内的字段，不新增表或迁移。
- 生效：`documentElement[data-accent]` 覆盖 `--accent / --accent-2 / --accent-3 / --accent-soft / --accent-wash / --unread / --on-accent`；`localStorage['rill.accent']` 只用于首屏前防闪烁，后端设置加载后为准。
- 选择器：阅读设置里的 24px 圆形色板，选中用 2px 墨色外圈；不用文字说明颜色含义。

字体：

- UI：`"Noto Sans CJK SC", "PingFang SC", "Source Han Sans SC", sans-serif`
- 标题与阅读：`"Noto Serif CJK SC", "Songti SC", "Source Han Serif SC", serif`
- 数字与代码：`"Noto Sans Mono CJK SC", ui-monospace, monospace`

圆角与层级：

- 小控件 8px，卡片/输入 12px，弹层与大面板 16–18px，标签与筛选使用胶囊。
- 按钮、工具栏、筛选、源列表行和选中态不加投影；卡片用边框 + 纸色差 + 极轻阴影。
- 弹层允许 `0 24px 60px` 级别阴影；Toast 允许轻量阴影。
- 应用背景使用低对比度纸张点纹；品牌使用强调色圆角印章。文章标题与正文之间不放装饰分隔线（2026-11-01 用户决策去除原标题短强调色线）。
- 动效只用于展开、抽屉、Toast 和阅读进度，遵循 `prefers-reduced-motion`。

## 页面结构

- **侧边栏**：紧凑品牌区（约 51px 高，Wordmark 24px / 印章 22px）→ 「全部 / 收藏」两项 → 订阅源树 → 左下角设置/深浅色图标组。品牌区和底部工具组不画横向分隔线，不显示「正常」状态胶囊；不再显示收件箱、未读、已读或单独的主题行。订阅源树按多级分组缩进展示源；源与分组支持右键/长按菜单编辑、删除、移动，桌面可拖拽源到分组/未分组、拖拽分组嵌套或调整同级顺序；删除分组只把源移回未分组，不级联删源。订阅源区支持 Ctrl/Cmd/Shift 多选与批量移动/启停/刷新/删除、源名称/地址搜索、分组子树未读/失败聚合、全部标为已读、失败源聚合重试；折叠状态按设备持久化。上方「视图」区保存当前筛选/搜索/已读状态，最多 30 个。默认宽 224px（范围 180–320px），右缘可拖动；宽度存 `settings.reader.rail_width`。
- **阅读三栏**：左栏默认 224px，中栏默认 384px（范围 300–520px），两栏右缘均可拖动并持久化；首屏用 localStorage 防跳变，后端设置加载后为准。中栏标题 20px、条目标题 17px（移动 16px）、摘要 12px（移动 11.5px）、时间 10px（移动 9.5px）；列表头只保留标题、搜索、全部已读和单个已读状态筛选图标；不显示数量徽标与排序切换，列表固定按发布时间降序。筛选图标循环「全部 → 仅未读 → 仅已读」，依次使用漏斗 / 圆点 / 对勾，非全部状态用强调浅底；列表顶部行与详情 topbar 同为 54px（移动端 47px），图标同一水平行，两处 topbar 不设底边框，搜索框与源告警以浮层展开。条目未读点为订阅源 name 行左侧 6px 圆点并与该行垂直居中；正文首图可用时在标题行右侧显示 64px（移动端 56px）正方形封面，摘要独占一行，无图不占位。中栏不再重复筛选 chips 或统计 meta；列表行不放全屏 / 收藏 / 已读按钮，这些操作只在详情右上角出现。列表支持多选（Ctrl/Cmd、Shift 范围）与批量已读/未读、收藏、稍后读、隐藏；列表头可切换跨源重复合并，重复行显示「+N 源」；`⌘K` / `Ctrl+K` 打开命令面板跳转源/分组/设置或直接搜索文章。正文区使用白色阅读面，标题 24–34px；AI 摘要和翻译在正文与专注阅读右栏都使用同一套卡片语言，专注栏使用紧凑尺寸。
- **详情页**：操作只在顶部工具栏，不在正文底部重复收藏 / 专注 / 外链。桌面右上角翻译图标打开紧凑浮层（译文 / 原文 / 双语）；移动端与专注右栏保留翻译面板。文章顶部的来源名称/图标是源诊断入口，不再使用语义不清的三点图标；来源、时间、作者同排，不用 `·` 等分隔符，也不单独占一行作者；正文不显示 `X` / `公众号` 等平台标签。AI 摘要常显，不提供折叠箭头；AI 图标统一为魔杖星点。桌面右侧固定显示 40px 环形阅读进度，回到顶部为独立的 40px 圆形按钮，两者尺寸一致；顶部时按钮禁用，≤760px 隐藏。播客条目在标题与 AI 摘要之间显示播放器：播放/暂停、进度条、±15 秒、0.75–2× 倍速；播放位置写入服务端并在本地缓存。已读筛选图标保持最初的漏斗 / 圆点 / 对勾三态。工具栏提供「复制 Markdown」与「下载 Markdown」：导出始终是原文；下载走 blob 锚点，交给懒猫 file-chooser 选择本地或懒猫保存。工具栏与正文笔记区提供稍后读、朗读（浏览器 SpeechSynthesis）与笔记/高亮；选中正文后添加笔记会带入摘录，摘录在正文内联显示，笔记可编辑/删除。
- **全屏阅读**：顶部用 `minimize`（退出全屏）图标退出，不使用返回箭头；不显示订阅来源和阅读设置；AI 摘要放在标题下方、正文上方；正文标题字号与普通阅读一致（24–34px，移动端 23px）；翻译面板保留在右侧栏/移动端正文前。
- **设置弹窗**（REQ-023 重设计）：底部设置图标打开浮层；无标题栏，左列 200px「设置」字标 + 纯文字目录（订阅源 / 阅读 / AI / 自动化 / MCP / 备份 / 安全，2026-11-01 用户决策去除菜单图标），右侧白面工作区滚动；关闭按钮悬浮内容区右上；标题栏不显示「保存中 / 已同步」状态。内容按 RowGroup/Row 行式组织，无卡片、无图标方块。阅读分类：主题（浅色 / 深色 / 跟随系统）、主题色色板、实时预览与字号 / 行宽 / 行高滑杆（单列）；行为开关两个。AI 分类：能力开关、连接（地址 / 模型 / 密钥 / 测试）、摘要（样式 / 上限 / 用量）、翻译（语言 / 内容外发确认）。自动化分类：定时报告、推送渠道、过滤规则与已过滤条目。MCP 分类：启用开关、接入地址、命名 Token 列表（创建、启停、吊销）与能力边界；完整 Token 只在创建时显示一次。备份分类：自动备份、手动操作（恢复为危险组并保留破坏性说明）、备份范围。安全分类：账号与会话、Feed 令牌（默认 masked，按需显示完整值、复制与隐藏）、安全边界（出站抓取仅允许 http/https，与 DEC-015 一致）。公众号接入（开关 / 微信读书扫码）并入订阅源分类，不再单设分类。移动端 `/settings` 是两级页面：分类目录列表 → `/settings/:section` 详情，不再使用 3×2 网格导航。
- **订阅源**：设置内管理。工具行 = 搜索 + 状态计数胶囊（全部 / 正常 / 需关注 / 已暂停）+ 添加源 + 更多菜单（管理分组 / 导入 OPML / 导出 OPML）；登录态过期告警置顶并直达扫码；按多级文件夹缩进的行式源树，源行展示图标、名称、类型标签、状态与刷新信息，启停 switch 常驻，编辑 / 刷新 / 删除在行内，点击行进源诊断；树下方为公众号接入行组。新增源时在弹窗内选择文件夹或「不分组」，默认不分组；添加源弹窗提供「链接 / ID」与「搜索创作者」，后者按平台分组候选并支持多选批量订阅。
- **源诊断**：源身份 + 状态 + 操作 → 指标卡 → 趋势/静默检测 → 抓取历史/备用源/输出。危险区独立卡片。返回源管理会回到设置弹窗的订阅源分类。
- **登录**：单卡片居中，只保留 72px 品牌图标、Wordmark、懒猫 OIDC 登录按钮与失败重试；进入页面不自动跳转，必须点击按钮后再发起 OIDC。不放产品定位、密码说明、服务健康状态和版本号。密码输入只在本地 `RILL_AUTH_MODE=password` 开发模式出现，LPK 不展示。favicon、登录图标与 LPK 图标必须来自同一 `web/public/icon.png` 图形（2026-11-02 换为用户提供的猫猫 RSS 图，圆角透明底，衍生 512/180/64 三档）。

## 文案规则

- 标题用名词短语：`订阅源`、`源诊断`、`阅读排版`、`摘要与翻译`、`备份与恢复`。
- 按钮用动词：`添加源`、`立即刷新`、`保存密钥`、`确认标记`。
- 删除装饰性解释：
  - 不写「这些偏好会写回后端设置……」这类实现说明。
  - 不写「先登记源，再决定它怎么被读」这类口号。
  - 不写重复标题含义的副标题。
- 保留必要说明：
  - 内容外发确认、AI 开关影响范围。
  - 登录态过期、抓取暂停、可能停更。
  - 删除/恢复不可逆、Token 泄露风险。
  - 失败原因、重试方式、输入限制。

## 可访问性与响应式

- 所有可点击元素有 hover、focus-visible 和禁用态；图标按钮必须有 `aria-label`。
- 浅色/深色正文对比度至少 4.5:1；状态不能只靠颜色，必须有文字或点 + 文案。
- 断点：1200 / 1040 / 900 / 760 / 520 / 320；760 以下列表与阅读分级，底部导航保留为浮动椭圆胶囊，选中只高亮 icon 与文字，不铺整项底色。
- 页面在 320px 宽度不得出现横向滚动；长 URL 可换行或截断，但复制入口保留。
