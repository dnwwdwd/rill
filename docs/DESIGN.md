# Rill 设计规范（DESIGN）

> 版本：0.1.7 · 2026-11-13
> 状态：现行。新增或修改任何页面、组件、样式、用户可见文案前必须遵循。
> 适用：[`web/`](../web/)；[`designs/rill-prototype/`](../designs/rill-prototype/) 仅作 v0.1 交互参考，主题与尺寸以本文件为准。
> 关联：[PRD.md](../PRD.md)、[PDD.md](../PDD.md) §6.5、[DOCUMENT_MAP.md](../DOCUMENT_MAP.md)、[REQ-023](requirements/REQ-023-settings-redesign.md)、[REQ-039](requirements/REQ-039-sidebar-tree-context-drag.md)、[REQ-040](requirements/REQ-040-pinned-and-watched-sources.md)。

## 0. AI 必读：硬性规则

1. **先复用，再新增。** 优先使用现有 `Button`、`IconButton`、`Segmented`、`Field`、`SearchField`、`Switch`、`Modal`、`RowGroup`、`Row`、`SourceIcon`；不要为单个页面另造一套按钮、tab、卡片或表单。
2. **布局承担解释。** 能用分组、间距、对齐说明的事情，不写第二行说明；不写重复标题含义的副标题。
3. **设置页用行式，不用卡片墙。** 设置内容一律 `RowGroup` + `Row`，组头是 11px 眉题，行间 1px 细线；不要给每个设置项套白卡片、图标方块或阴影。
4. **Tab / Segmented 默认只占内容宽度。** 外层容器同样不得占满；设置项、弹窗字段、工具栏中的 tab 必须 `align-self: flex-start` 或放在 `Row` 的右侧 `control` 槽。禁止 `width: 100%`、`flex: 1`、`justify-content: space-between` 把 tab 拉满整行。
5. **图标和头像是固定尺寸。** `SourceIcon`、状态图标、chevron 一律 `flex: none`；行高由文字行数和上下 padding 决定，不能靠压缩图标腾空间。
6. **不要写宽泛选择器。** 禁止用 `.field input` 顺手排版复选框，禁止用 `.某一行 > span` 给所有子 `span` 排版；必须给文字区、勾选区、图标区各自的 class。复选框在 `.field` 内必须覆盖为 15–16px、`padding: 0`、`accent-color: var(--accent-3)`。
7. **主操作只出现一次。** 同一动作不在列表行、正文底部、详情顶部重复出现；详情操作统一在右上角工具栏。
8. **不靠颜色单独传达状态。** 状态必须有文字、图标或形状辅助；危险操作用 `--danger`，不跟随主题色。

## 1. 设计语言

**黑白纸页，强调色作印。** 界面由近黑文字、白色面板、浅灰工作区和 1px 细线组织。默认强调色是品牌蓝（`blue`）：`#4C5EE8` 用于文字与链接，`#5B6CF0` 用于品牌、开关、未读和进度。用户可切换 9 套强调色，但只改变强调色层，不改变纸张、正文和语义状态色。

整体气质：克制的工具型应用。纸张微纹理、细线、留白、极轻的卡片层次；不使用大面积渐变、彩色卡片、厚重投影或营销式大标题。

### 1.1 层级

- 页面与侧栏：`--paper`
- 列表与阅读面：`--paper-2`
- 卡片、弹层、输入：`--surface`
- 工具栏、表头、次级面板：`--surface-2`
- 分隔：`--line`；输入与描边：`--line-strong`

### 1.2 圆角与阴影

- 小控件 8px，卡片/输入 12px，大面板 16px；弹窗 18px；设置弹窗 14px。
- 按钮、工具栏、筛选、源列表行、选中态不加阴影。
- 卡片允许 1px 细线 + 纸色差 + 极轻阴影；弹层允许 `--shadow-lg`；Toast 允许轻量阴影。
- 标签、筛选、tab 使用胶囊；不要混用直角和胶囊。

### 1.3 动效

- 只用于展开/收起、抽屉、Toast、阅读进度和轻量淡入。
- 必须尊重 `prefers-reduced-motion`；不要给列表滚动或常规 hover 加大幅位移。

### 2.2 字体

- UI：`"Noto Sans CJK SC", "PingFang SC", "Source Han Sans SC", "Microsoft YaHei", sans-serif`
- 标题与阅读：`"Noto Serif CJK SC", "Songti SC", "Source Han Serif SC", "STSong", serif`
- 数字与代码：`"Noto Sans Mono CJK SC", "SFMono-Regular", "JetBrains Mono", "Roboto Mono", monospace`

### 2.3 排版尺度

| 场景 | 字号 / 行高 | 说明 |
| --- | --- | --- |
| 页面/列表主标题 | 20–24px / 1.2 | 衬线，600 |
| 文章标题 | 24–34px / 1.25 | 衬线；移动端 23–28px |
| 阅读正文 | 18px / 1.85 | 用户可调；行宽默认 680px |
| 弹窗标题 | 24px / 1.25 | 衬线，600 |
| 设置分组眉题 | 11px / 1.4 | 大写字距 `.18em`，弱化色 |
| 设置行标题 | 13px / 1.5 | 正文色 |
| 设置行说明 | 11px / 1.6 | 弱化色，最多 52ch |
| 列表条目标题 | 17px / 1.35 | 移动端 16px |
| 列表摘要 | 12px / 1.6 | 移动端 11.5px |
| 元数据/时间 | 9–10px | 只用于辅助信息，不用于正文 |
| 按钮文字 | 12–13px | 与控件高度匹配 |

原则：正文不小于 12px；9px 只用于脚注、时间、角标等非关键信息。中英文混排保持同一行基线，不用 `·` 强行拼接来源、时间、作者。

### 2.4 间距

- 基础节奏：4 / 6 / 8 / 12 / 16 / 20 / 24 / 30px。
- 行内元素 6–10px；表单项之间 14–18px；设置分组之间 30px。
- 页面内容左右留白 22–26px；弹窗内容 20–24px；移动端可降到 16–18px。
- 不要用大段空白制造“高级感”，信息密度优先。

## 3. 布局范式

### 3.1 应用外壳

- 桌面三栏：侧栏 224px（180–320 可拖）→ 列表 384px（300–520 可拖）→ 详情自适应。
- 中栏列表头与详情 topbar 同高：桌面 54px，移动 47px；两者都不加底边框。
- 侧栏底部工具组固定，不参与源树滚动。
- 移动端：列表与详情分级；底部导航为浮动椭圆胶囊，选中只高亮 icon 与文字，不铺整项底色。

### 3.2 设置页（弹窗与移动页）

- 桌面：960px 宽、高 `min(780px, 90vh)`、14px 圆角；左列 200px 目录，右列白面工作区。
- 左列：12px「设置」字标 + 14px 纯文字导航；行高 42px、9px 圆角；选中用 `--accent-soft` 背景 + 强调色文字。
- 右列：`padding: 22px 56px 30px 26px`，关闭按钮悬浮右上；内容独立滚动，页面本身不滚动。
- 移动端：`/settings` 分类目录 → `/settings/:section` 详情，不用 3×2 网格。
- 设置分组统一 `RowGroup`：组头 11px 眉题，无图标、无横向装饰线；危险组文字用 `--danger`。
- 设置行统一 `Row`：左标签 + 右控件；行 `padding: 11px 0`，底部 1px 细线，最后一行去线。
- 控件必须右对齐且按内容宽度；输入框、二维码、清单等需要整行的内容才允许 `flex-basis: 100%`。

### 3.3 弹窗

- 默认宽度 `min(520px, 100%)`；宽弹窗 `min(680px, 100%)`。
- 18px 圆角；头部 24px 衬线标题 + 最多一行 10px subtitle；正文独立滚动；footer 右侧操作，左侧可放 9px 说明。
- 一个弹窗只做一件事；复杂配置放设置页，不塞进弹窗。
- 弹窗内字段使用 `.field`：标签在上、控件在下；字段之间 14–16px。
- tab / segmented 在弹窗字段内必须左对齐、内容宽度。

### 3.4 列表、树与批量操作

- 源树行高约 40px，每级缩进 18px；行操作不依赖 hover，常用状态常驻。
- 源行：图标固定尺寸 + 名称（可省略）+ 状态/计数；未读 dot 在名称行左侧并垂直居中。
- 批量管理统一模式：`批量管理` → 行前出现 checkbox → 工具条显示「已选 N / 全选 / 清空 / 批量动作 / 取消选择」。
- 批量工具条使用现有 `.st-batch`，允许换行；不要为批量操作另造浮动工具条。
- 多选列表（如添加关注源）使用搜索 + checkbox 列表 + 全选/清空 + 已选数量；行高 38–40px，头像 22–26px。
- 长列表必须限高滚动（例如 `max-height: min(60vh, 420px)`），并保留 `overscroll-behavior: contain`。

### 3.5 空状态与反馈

- 空状态：图标/印章 + 标题 + 一句必要说明 + 主操作；不写营销文案。
- 加载：优先骨架屏；局部操作显示行内状态或按钮 busy 文案。
- Toast 只报结果，不报实现细节；失败信息必须说明原因或下一步。

## 4. Tab / Segmented 专项规则

> 这是最容易复发的布局问题，单独列出。参考实现：[`web/src/components/sources/WatchSourceDialog.tsx`](../web/src/components/sources/WatchSourceDialog.tsx) 与 [`web/src/styles/index.css`](../web/src/styles/index.css) 中的 `.watch-source-options .segmented`。

1. `Segmented` 容器默认 `display: inline-flex`，宽度由按钮内容决定。
2. 放在 `display: flex; flex-direction: column` 的字段或卡片里时，必须显式 `align-self: flex-start`；放在 grid 里时用 `justify-self: start`。
3. 放在 `Row` 中时使用右侧 `control` 槽，不要放到左侧 `label` 下面再拉伸。
4. 禁止给 tab 容器设置 `width: 100%`、`flex: 1` 或让子按钮 `flex: 1` 填满整行。
5. 如果按钮文字太短、点击区不够，增加按钮自身 `padding` 或 `min-width`，不要拉宽外层容器。
6. 只有两类存量例外可以保持整行：添加源弹窗的「链接 / 搜索创作者」主模式切换，以及 ≤760px 的翻译面板。新增页面不得再增加整行 tab。

## 5. 组件规范

| 组件 | 规则 |
| --- | --- |
| `Button` | 主按钮实心强调色、无阴影；次按钮白面 + 细线；危险按钮红描边；高度 32 / 36 / 44；图标与文字间距 7px |
| `IconButton` | 32×32 命中区；hover 浅灰底；active 用强调浅底；必须有 `aria-label` 和 tooltip |
| `Field` | 标签在上，输入 34–36px；focus 用 2px 强调浅底 ring；提示只在影响输入正确性时保留 |
| `SearchField` | 统一搜索输入，左侧搜索图标，右侧清除；不各页面手写 |
| `Segmented` | 胶囊容器，选中项实心强调色；只用于 2–3 个互斥视图；**宽度默认 hug 内容** |
| `Switch` | 34×20px；关闭态 `--line-strong`，开启态强调色；行内开关不要文字化 |
| `Tag` | 小号胶囊；来源类型使用中性/强调色；可带 12px 图标 |
| `SourceIcon` | 固定正方形，优先后端同源图标，失败用首字母；`flex: none`，不跟随主题色 |
| `RowGroup` / `Row` | 设置页唯一基本件；组头 11px 眉题，行左标签右控件，1px 细线；不要卡片化 |
| `Modal` | 18px 圆角、遮罩模糊；标题简短，subtitle 最多一行；footer 右侧操作 |
| `ArticleRow` | 源、时间、标题、摘要、收藏标记、可选方形封面；列表行不放全屏/收藏/已读按钮 |
| `ReadingProgress` | 桌面详情右侧 40px 环形进度 + 40px 回顶按钮；顶部禁用，≤760px 隐藏 |
| `Notice` | 信息/警告/危险三档；标题 + 一行说明 + 可选操作；不用于装饰 |
| `EmptyState` | 图标/印章 + 标题 + 一句说明 + 主操作 |
| `TranslationCard` / `AiSummaryCard` | 白面卡片；图标方块 + 标题 + 内容；AI 摘要常显，不折叠 |

## 6. 页面结构

- **侧栏**：品牌区 → 全部/收藏 → 视图 → 订阅源树 → 底部工具组。源树支持多级分组、右键/长按菜单、拖拽、多选批量、搜索、分组未读/失败聚合、全部已读、失败重试、折叠持久化。置顶源集中显示在源树顶部，不重复出现在原分组；关注源未读显示 5px 圆点，隐藏条目不计入。
- **阅读三栏**：左栏源树，中栏列表，右侧详情。列表头只保留标题、搜索、全部已读、已读状态筛选；固定按发布时间降序。条目未读点在源名行左侧；首图 64px 方形封面放在标题行右侧，无图不占位。
- **详情页**：操作只在右上角工具栏（专注、翻译、外链、复制/下载 Markdown、复制订阅地址、收藏、已读、稍后读、朗读）。来源名称是源诊断入口；正文不显示平台标签，不在底部重复操作。
- **专注阅读**：顶部用 `minimize` 退出，不显示来源和阅读设置；AI 摘要放在标题与正文之间；翻译保留在右栏或移动端正文前。
- **设置**：订阅源 / 阅读 / AI / 自动化 / MCP / 备份 / 安全。公众号接入并入订阅源；自动化含关注订阅源、报告、推送渠道、过滤规则；MCP 含启用、地址、命名 Token 与能力边界。
- **订阅源设置**：搜索 + 状态胶囊 + 添加源 + 更多菜单；行式多级源树；下方公众号接入。添加源支持「链接/ID」与「搜索创作者」，候选按平台分组、多选批量订阅。
- **源诊断**：源身份与状态 → 指标卡 → 趋势/静默 → 抓取历史/备用源/输出；危险区独立。
- **登录**：单卡片居中，只保留品牌图标、Wordmark、懒猫 OIDC 登录按钮与失败重试；进入页面不自动跳转。

## 7. 文案规则

- 标题用名词短语：`订阅源`、`源诊断`、`阅读排版`、`摘要与翻译`、`备份与恢复`。
- 按钮用动词：`添加源`、`立即刷新`、`保存密钥`、`确认标记`。
- 删除装饰性解释：不写实现说明、不写口号、不写重复标题的副标题。
- 保留必要说明：内容外发、AI 影响范围、登录态过期、抓取暂停、删除/恢复不可逆、Token 泄露风险、失败原因与重试方式。
- 数字、路径、Token 用等宽字体；日期时间统一格式，不混用相对时间和绝对时间。

## 8. 可访问性与响应式

- 所有可点击元素有 hover、focus-visible、禁用态；图标按钮必须有 `aria-label`。
- 浅色/深色正文对比度至少 4.5:1；状态不能只靠颜色。
- 断点：1200 / 1040 / 900 / 760 / 520 / 320。
- 760 以下列表与阅读分级；520 以下表单单列、按钮可换行。
- 320px 宽度不得横向滚动；长 URL 可换行或截断，但复制入口保留。

## 9. 新增页面检查清单

提交 UI 前逐项确认：

- [ ] 是否复用了现有组件与 token，而不是新造样式？
- [ ] tab / Segmented 是否只占内容宽度？外层有没有被 `flex` 或 `width: 100%` 拉满？
- [ ] 设置项是否使用 `RowGroup` / `Row`，控件是否右对齐且 hug 内容？
- [ ] 图标、头像、chevron 是否 `flex: none` 且尺寸固定？
- [ ] 复选框是否避免了 `.field input` 的整行输入框样式？
- [ ] 列表行是否有足够行高，名称/说明是否分行，长文本是否省略或滚动？
- [ ] 空状态、加载、失败、禁用态是否完整？
- [ ] 文案是否删掉了重复解释和实现细节？
- [ ] 320px、760px、1200px 是否无横向滚动和控件重叠？
- [ ] 浅色/深色下对比度、状态色和强调色是否正常？
